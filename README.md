**Nova Chat** is a lightweight, fully open-source messaging application designed for Android devices. Built with privacy and performance in mind, it provides a clean user experience completely free of tracking frameworks and proprietary dependencies.

---

## 🌟 Key Features

* 🔓 **100% Free & Open Source (FOSS):** Contains no proprietary code, tracking SDKs, or third-party analytics.
* 🚫 **Google-Free (No GMS / Firebase):** Fully independent of Google Play Services, making it ideal for custom ROMs and privacy-focused setups.
* ⚡ **Native Performance:** Core performance-critical components are implemented in C and C++ for minimal resource overhead and maximum responsiveness.
* 🛡️ **Privacy First:** No personal data collection or external server telemetries.

---

## 🛠️ Tech Stack

* **Primary Languages:** Kotlin, C, C++
* **User Interface:** Native Android UI
* **Build System:** Gradle & CMake
